# Outline

1. Informal reasoning
   - proofs
   - fixpoints (induction, coinduction)
2. Deductive formalisms ("logic")
   - syntax (rules) vs semantics (models)
   - propositional, predicate, modal
   - decision procedures (SAT, SMT)
3. Functions
   - $\lambda$-calculus, typed $\lambda$
   - rewriting, structured operational semantics (SOS)
   - propositions-as-types
4. Imperative programs
   - operational vs denotational vs axiomatic
   - partial correctness vs termination / safety vs liveness
   - Hoare, temporal logics
5. Concurrency / processes
   - $\mu$-calculus, CCS (process algebra)
   - (bi)simulation
   - Petri nets, VASS
6. Circuits
   - combinational, sequential, dataflow
   - Kahn nets, I/O interface theories
7. State-based formalisms
   - finite automata, $\omega$-automata, graph games
   - infinite-state extensions: pushdown, timed, probabilistic (MDPs etc)
